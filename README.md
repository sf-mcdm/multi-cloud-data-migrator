# Salesforce Multi-Cloud Data Migrator 🚀

The **Salesforce Multi-Cloud Data Migrator** is a powerful and resilient software for migrating large, complex data volumes between Salesforce orgs.

## 📚 Documentation & Installation

**For everything including full documentation, installation guides, configuration details, and support, please visit our official website:**

👉 **[https://www.sf-mcdm.com](https://www.sf-mcdm.com)** 👈

---

### Quick Start

**Installation:**
```bash
sf plugins install sf-mcdm/multi-cloud-data-migrator
```

**Launch the Web App 🚀:**
```bash
sf multi-cloud-data-migrator:ui
```

*(For all further instructions, please refer to the website!)*
